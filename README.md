# Black Cuts — site base com imagens

Projeto pronto para editar e publicar.

## Estrutura
- index.html — conteúdo e estrutura
- style.css — visual, responsividade e animações
- script.js — menu, scroll reveal e interação dos cards
- imagens/ — imagens extraídas da mesma composição visual gerada para o projeto

## Antes de usar com um cliente
1. Troque "BLACK CUTS" pelo nome da barbearia.
2. Troque o número `5500000000000` pelos dados reais de WhatsApp.
3. Troque os links de Instagram e Facebook.
4. Substitua endereço, horários e informações do FAQ.
5. Se for um site comercial, prefira fotos reais fornecidas pelo cliente ou imagens com licença adequada.

## Publicação
Pode subir esta pasta para um repositório no GitHub e conectar o repositório ao Vercel.
